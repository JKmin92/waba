# 🐾 WABA 반려동물 히스토리 & 라이프 아카이브 기획 아이디어 노트

본 문서는 추후 고도화 단계에서 구현할 반려동물 특화 기능(애착 아이템 큐레이션, 소셜 프로필 확장, AI 기반 건강 히스토리 자동 추출)에 대한 기획 및 기술 명세서입니다.

---

## 🛋️ 아이디어 1. 아이의 애착 가구 & 꿀템 모아보기 (Pet's Favorite Objects)

### 1. 기획 배경
- 집사들은 내 아이가 어떤 가구, 방석, 캣타워, 장난감을 좋아하는지 기록하고 자랑하고 싶어 함.
- 다른 집사들은 특정 품종/체형의 아이가 실제로 잘 쓰는 검증된 제품을 보고 구매하고 싶어 함.

### 2. 동작 메커니즘
1. **데이터 집계:**
   - 특정 반려동물(`pet_id`)이 태그된 사진 블록에 함께 꽂힌 **제품 핀(`product_pins`)**을 자동으로 연관 집계.
2. **마이페이지 노출:**
   - 마이페이지 펫 프로필 상세에 **[모아의 애착 아이템 TOP N]** 섹션 제공.
   - 예: *"모아의 공간에 가장 많이 등장한 아이템 (원목 캣타워 4회, 도자기 식기 3회, 논슬립 매트 2회)"*
3. **기대 효과:**
   - 자연스러운 커머스 구매 전환 (후기성 신뢰도 극대화).
   - "우리 아이 취향 컬렉션"을 완성하는 재미 제공.

---

## 🐾 아이디어 2. 타인 프로필로의 소셜 확장 ("모아의 팬 되기" / 펫 인플루언서 뷰)

### 1. 기획 배경
- 반려동물 커뮤니티에서는 '집사 개인'보다 '반려동물(모아, 두부)' 자체의 팬덤이 형성되는 경우가 많음 (인스타그램의 펫 계정 문화).

### 2. 동작 메커니즘
1. **타인 피드 / 프로필 확장:**
   - 다른 유저의 상세페이지나 프로필에 방문했을 때, 해당 집사의 펫 아바타/카드를 클릭 가능.
   - 클릭 시: **`모아의 공간 룩북 모아보기`** 전용 아카이브 페이지 또는 바텀시트 오픈.
2. **펫 프로필 카드 구성:**
   - 펫 대표 사진, 품종, 나이, 한 줄 소개 (예: *"성수동 거주 랙돌 모아의 인테리어 탐험기"*).
   - 모아가 등장한 룩북 그리드 + 모아의 애착 아이템 모음.
3. **기대 효과:**
   - 펫 중심의 감성적인 소셜 네트워크 형성.
   - 유저 간 팔로우 및 인터랙션 증가.

## 🤖 아이디어 3. AI 기반 일상 글 ➡️ 반려동물 건강/생애 이벤트 자동 추출 (Smart Auto-Journal)

### 1. 기획 배경
- 집사들은 일상 글을 쓰지만("어제 우리 모아 중성화 수술 무사히 마쳤어요"), 별도의 병원 수첩 폼에 날짜와 질병명을 또 입력하는 것은 번거로워함.

### 2. 동작 메커니즘 (AI 백그라운드 추출)
1. **자연어 분석 (Gemini Flash 연동):**
   - 게시글 작성/수정 시 본문 텍스트와 펫 정보를 백그라운드 AI에 전달.
   - 예: *"어제 우리 모아 중성화 수술 무사히 마쳤어요 ㅠㅠ 넥카라 하고 자는데 짠하네요"*
   - AI 추출 결과:
     ```json
     {
       "has_event": true,
       "pet_name": "모아",
       "event_type": "SURGERY_NEUTERING",
       "event_name": "중성화 수술",
       "estimated_date": "2026-11-11",
       "summary": "중성화 수술 완료 및 넥카라 착용",
       "source_post_id": "P913261111110700"
     }
     ```
2. **스마트 확인 UX (Zero Effort):**
   - 글 작성 완료 직후 또는 마이페이지 펫 카드에 작고 스마트한 알림 표시:
     - 💡 *"방금 작성하신 글에서 '2026.11.11 중성화 수술' 기록을 발견했어요. 모아의 건강 수첩에 등록할까요? [원클릭 등록]"*
3. **기대 효과:**
   - 사용자는 그냥 일기 쓰듯 자연스럽게 글만 썼을 뿐인데, 아이의 평생 의료/건강 기록이 자동으로 쌓이는 감동적인 경험 제공.
