# 게시글 삭제, 보관 및 신고 삭제 이의 제기 정책 (FAQ 초안)

> 추후 서비스 내 **고객센터 · FAQ 페이지**에 게시할 운영 정책 정리 문서입니다.

---

## Q1. 내가 삭제한 게시글이나 첨부 사진은 바로 사라지나요?
* 게시글을 삭제하면 **즉시 커뮤니티 피드 및 검색에서 비공개(`삭제` 상태)** 로 전환됩니다.
* 다만 실수 삭제나 분쟁 확인 등을 위해 삭제일로부터 **30일간 서버에 안전하게 보관**되며, **30일이 지나면 게시글 데이터(DB)와 첨부된 이미지 파일까지 모두 영구 삭제**됩니다.

---

## Q2. 신고나 관리자 조치로 내 게시글이 삭제되었을 때는 어떻게 되나요?
* 신고 접수 또는 운영 정책 위반으로 관리자가 게시글을 삭제한 경우에도, **삭제일로부터 30일간 보관**된 후 DB 및 첨부 이미지가 영구 삭제됩니다.
* 보관 기간(30일) 동안에는 **마이페이지 > 내 활동 > `신고 삭제 / 이의제기`** 메뉴에서 삭제된 게시글과 삭제 사유, 영구 삭제 예정일을 직접 확인할 수 있습니다.
* 영구 삭제 예정일(기본 30일, 연장 기간 포함)이 지나면 **게시글과 이미지가 완전히 삭제되며 마이페이지 목록에서도 사라지고 더 이상 이의를 제기할 수 없습니다.**

---

## Q3. 신고로 삭제된 게시글에 대해 이의를 제기하고 싶어요. 언제까지 가능한가요?
* **관리자가 신고 승인으로 게시글을 삭제한 날로부터 30일 이내(영구 삭제 예정일 전까지)** 마이페이지에서 이의 제기를 접수할 수 있습니다.
* 이의 제기가 접수되어 **관리자가 타당하다고 판단해 승인하면 게시글과 첨부 이미지가 원래 상태로 복구**됩니다. (신고자에게는 별도 알림이나 전체 공지가 발송되지 않으며, 관리자 이력으로만 관리됩니다.)
* **반려 시 재이의 제기**: 이의 제기가 반려된 경우에도 마이페이지에서 **반려 사유를 확인하고 다시 이의 제기를 신청**할 수 있습니다.
  * 단, **3회를 초과(4회차 이상)** 하여 반복 이의 제기가 진행되는 경우, 관리자가 추가 이의 제기를 차단하는 사유와 함께 반려할 수 있으며 이후 해당 게시글에 대한 재이의 제기는 불가합니다.

### 삭제 예정일이 얼마 남지 않았을 때 이의 제기를 하면 어떻게 되나요?
* 영구 삭제 예정일까지 **10일 미만으로 남은 상태에서 이의 제기를 접수하면, 심사 기간 확보를 위해 남은 일수에 자동으로 `+10일`이 연장**됩니다. *(자동 `+10일` 연장은 게시글당 최초 1회 적용)*
  * 예) 영구 삭제까지 `4일` 남은 상태에서 이의 제기 → **`14일 뒤`** 로 자동 연장
* 또한 관리자는 심사가 추가로 필요한 경우 사유를 기록해 **최대 `+30일`까지** 삭제 예정일을 추가 연장할 수 있습니다.

---

## Q4. 임시저장(`DRAFT`) 글은 얼마나 보관되나요?
* 작성 중인 임시저장 글은 **마지막 저장(수정)일로부터 30일간 보관**됩니다.
* 30일 동안 새로운 내용 추가·수정 없이 방치된 임시저장 글은 DB와 첨부 이미지가 자동 삭제됩니다.
* **보관 중인 임시저장 글을 불러와 다시 수정·저장하면 그 시점부터 30일 보관 기간이 새롭게 갱신**됩니다.
* 마이페이지(임시저장 탭)와 글쓰기 에디터(임시 저장 보관함)에서 각 글의 **자동 삭제 예정일(`YYYY.MM.DD`)과 남은 일수(`D-N`)** 를 확인할 수 있습니다.

| **유저 직접 삭제 게시글** | 삭제일로부터 **30일** | DB 행 + 첨부 이미지 완전 삭제 | - |
| **신고 / 관리자 삭제 게시글** | 삭제일로부터 **30일** | DB 행 + 첨부 이미지 완전 삭제 + 마이페이지 미노출 | 30일 이내 이의 제기 가능 (복구 시 원본 유지, 신고자 별도 통지 없음) |
| **반려 시 재이의 제기** | 횟수 제한 없음 | - | 3회 초과(4회차 이상) 반려 시 관리자가 재이의 차단 가능 |
| **이의 제기 시 자동 연장** | 잔여 `< 10일` 시 **+10일 자동 추가** | 연장된 예정일 경과 후 완전 삭제 | 게시글당 최초 1회 자동 연장 |

| **임시저장 (`DRAFT`)** | 최종 수정일로부터 **30일** | DB 행 + 첨부 이미지 완전 삭제 | 재저장 시 30일 자동 갱신 |
